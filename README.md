# MK Systems Web App

Marketing website targeted for a company that sells and implements business systems.

## What it includes

- B2B-focused hero messaging for systems sales
- Solutions, industries, and implementation process sections
- Contact form interaction with client-side confirmation message
- Responsive layout for desktop and mobile

## Run locally

Because this is a static web app, you can open it directly or serve it locally.

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Run a local server

From the project root:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
